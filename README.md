# 宠物拼豆图纸

本地静态网页，无登录、后端或付费 API。双击 `index.html` 即可使用；或运行 `npx serve .`。

照片处理全部在浏览器本地完成，不会上传到服务器。

功能：PNG/JPEG 上传、两种自动构图、24–96 网格、6–32 通用色、图纸 PNG 下载、浏览器打印为 PDF、颜色／豆数统计，以及同一张照片生成的“细节版／易拼版”双拼好效果预览。细节版增加颜色保留层次，易拼版减少颜色并清理明显的孤立碎格；两版都由各自图纸的同一份格子数据逐颗渲染。

为了在有限格子里保住宠物主体，用户还可以：

- 在画面边缘点 1–3 个背景样本，只清除与边缘连通的相近颜色；中央误点会被拒绝。
- 沿宠物外缘点 6–16 个主体轮廓点，只保留轮廓内格子；面积太小或无效不会应用。
- 分别点眼睛、鼻口或独特花纹（每类最多 3 点），将取样色作为量化色板的固定锚点。
- 一次下载 5 张同源过程图：源图分析、细节图纸、易拼图纸、细节预览、易拼预览，用于展示可追溯的设计过程。

这些是人为可检查的取舍，不是自动抠图或 AI 重绘。真实品牌色号、采购清单和实体拼制仍未接入／验证。

效果预览用于在制作前比较两种方案；色号是通用 RGB，不是 MARD 或 Artkal 采购色号。当前不含 AI 重绘／卡通化；若导入已处理的 AI 图片，图纸链路可正常使用。对外介绍时可称为“拼好效果预览”，不要称为实拍样品。
