# 宠物拼豆图纸

本地静态网页，无登录、后端或付费 API。双击 `index.html` 即可使用；或运行 `npx serve .`。

照片处理全部在浏览器本地完成，不会上传到服务器。

功能：PNG/JPEG 上传、两种自动构图、24–96 网格、6–32 色、图纸 PNG 下载、带行列坐标的浏览器打印图纸、MARD 221 采购清单 CSV、格子坐标 CSV，以及同一张照片生成的“细节版／易拼版”双拼好效果预览。细节版增加颜色保留层次，易拼版减少颜色并清理明显的孤立碎格；两版都由各自图纸的同一份格子数据逐颗渲染。

为了在有限格子里保住宠物主体，用户还可以：

- 在画面边缘点 1–3 个背景样本，只清除与边缘连通的相近颜色；中央误点会被拒绝。
- 沿宠物外缘点 6–16 个主体轮廓点，只保留轮廓内格子；面积太小或无效不会应用。
- 分别点眼睛、鼻口或独特花纹（每类最多 3 点），将取样色作为量化色板的固定锚点。
- 一次下载 5 张同源过程图：源图分析、细节图纸、易拼图纸、细节预览、易拼预览，用于展示可追溯的设计过程。

这些是人为可检查的取舍，不是自动抠图或 AI 重绘。

## 色号与采购边界

v1 输出一个冻结的 **MARD 221 色号体系（A–H、M）／2.6 mm 市售规格线索**。每一个非背景格均映射到源色号与零填充市售下单核对代码（如 `A1 → A01`）；打印图纸、豆数统计、采购清单 CSV 和格子坐标 CSV 使用同一份格子数据。色板、来源、SHA-256、代码格式规则和采购边界见 [palette/MARD-221-SOURCES.md](palette/MARD-221-SOURCES.md)。

屏幕 RGB 是版本化算法匹配参考，**不等于实物颜色**。公开资料只支持“按该色号体系销售的 2.6 mm 补充豆存在”这一线索，不确认原厂 MARD、卖家、库存、批次或实物色差。下单前仍须在目标卖家页面逐项核对；不能把 MARD 同款、不同规格或其他品牌写成原厂等同。当前不含 AI 重绘／卡通化；若导入已处理的 AI 图片，图纸链路可正常使用。对外介绍时可称为“拼好效果预览”，不要称为实拍样品或实体复现。
